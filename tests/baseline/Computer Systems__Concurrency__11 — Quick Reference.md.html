Decision Tree (Text)

`` Critical section < 1 µs? ├── YES → Contention rare? │ ├── YES → std::mutex │ └── NO → Spinlock or lock-free └── NO → Read-mostly (writes < 10%)? ├── YES → std::shared_mutex └── NO → std::mutex + fine-grained locks Need to wait for condition? └── YES → std::condition_variable (NOT spin-polling) Real-time thread (can't sleep)? └── YES → Lock-free structure (no kernel) Multiple independent atomic vars same cache line? └── YES → alignas(64) each var `
