Reading x86-64 Assembly — Quick Reference

Why This Matters. When the compiler generates code from your C++, the CPU executes assembly — not C++. Profilers show you assembly. Debuggers disassemble to assembly. Crash dumps contain assembly. Understanding assembly is how you know WHAT your code actually does, not just what you think it does. This reference covers what you'll encounter most often.

Prerequisites

Prerequisites
You should understand registers conceptually (../Hardware/04 — CPU Architecture (coming soon)) and know that a CPU executes instructions one at a time (the fetch-decode-execute cycle). No prior assembly experience required.

1. The x86-64 Register Layout

64-bit general-purpose registers (16 total):
┌──────────┬────────────┬──────────────────────────────┐
│ Register │ Purpose    │ Sub-registers                │
├──────────┼────────────┼──────────────────────────────┤
│ RAX      │ Accumulator│ EAX (32), AX (16), AH/AL (8) │
│ RBX      │ Base       │ EBX, BX, BH/BL              │
│ RCX      │ Counter    │ ECX, CX, CH/CL              │
│ RDX      │ Data       │ EDX, DX, DH/DL              │
│ RSI      │ Source idx │ ESI, SI                      │
│ RDI      │ Dest idx   │ EDI, DI                      │
│ RSP      │ Stack ptr  │ ESP, SP (never use for data) │
│ RBP      │ Base ptr   │ EBP, BP (frame pointer)      │
│ R8-R15   │ General    │ R8D (32), R8W (16), R8B (8) │
└──────────┴────────────┴──────────────────────────────┘
Special registers:
RIP: Instruction pointer (points to NEXT instruction)
RFLAGS: Status flags (CF=carry, ZF=zero, SF=sign, OF=overflow)

The sub-register naming:

  • EAX = lower 32 bits of RAX (the E = Extended, from 32-bit days)
  • AX = lower 16 bits of RAX
  • AH = high 8 bits of AX, AL = low 8 bits of AX

3. The Calling Convention (x86-64 System V — Linux/macOS)

Arguments are passed in registers (first 6), additional args on the stack:

Arg #RegisterNotes
1stRDIInteger/pointer 64-bit arg
2ndRSI
3rdRDX
4thRCX
5thR8
6thR9
7th+[RSP+0], [RSP+8], ...Stack (caller pushes)
Return value: RAX (or RDX:RAX for 128-bit returns like __int128).

Callee-saved registers (must be preserved by callee): RBX, RBP, R12-R15.

Caller-saved registers (callee can clobber): RAX, RCX, RDX, RSI, RDI, R8-R11.

Windows x64 Calling Convention

Different! First 4 args in: RCX, RDX, R8, R9. Callee must reserve 32 bytes of "shadow space" for the first 4 args even if tiny. Different register set.

4. How C++ Constructs Map to Assembly

// C++:
int square(int x) { return x * x; }

; Assembly (-O2):
square(int):
 mov     eax, edi       ; edi = first arg (x), copy to eax
 imul    eax, edi       ; eax = eax * edi
 ret                     ; return value in eax

int arr[4] = {1, 2, 3, 4};
int sum = 0;
for (int i = 0; i < 4; i++) sum += arr[i];

; Assembly (-O2) — loop fully unrolled:
 mov     eax, 10        ; Compiler pre-computed the sum!
 ret

// Virtual function call:
class Base { public: virtual int Get() = 0; };
int Use(Base* b) { return b->Get(); }

; Assembly (-O2):
 mov     rax, [rdi]     ; Load vtable pointer from object at rdi
 call    [rax]          ; Call first vtable entry (Get())
 ; rax contains return value from Get()

Use -masm=intel with GCC/Clang to get Intel syntax in compiler output:

g++ -S -masm=intel -O2 main.cpp    # Assembly in Intel syntax
objdump -d -M intel mygame         # Disassemble in Intel syntax

6. Common Patterns to Recognize

Function Prologue

push    rbp              ; Save old base pointer
mov     rbp, rsp         ; Set frame pointer
sub     rsp, 32          ; Allocate 32 bytes of local variables

Function Epilogue

leave                    ; mov rsp, rbp; pop rbp   (or manually)
ret

If-Else

cmp     eax, 10         ; Compare argument to 10
jne     .Lelse          ; Jump if not equal
                     ; ... if-body ...
jmp     .Lend
.Lelse:
                     ; ... else-body ...
.Lend:

Loop

.Lloop:
                     ; ... loop body ...
dec     ecx             ; decrement counter
jne     .Lloop          ; jump if counter not zero

Switch (Jump Table)

mov     eax, [rbp-4]    ; Load switch variable
jmp     [.jump_table + rax*8]  ; Direct jump through table

Two-Way Explanation

Simple

Assembly is the lowest language the CPU speaks. Every C++ if, for, and function call compiles down to a handful of assembly instructions: mov (copy data), add/sub/imul (math), call/ret (function calls), cmp/je/jne (decisions). Reading assembly means reading the exact instructions the CPU executes — no compiler optimization hiding anything. Each instruction is tiny: mov rax, rbx means "copy the value from register RBX into register RAX." Learn 20 instructions and you can read any function's assembly.

Technical

x86-64 uses a variable-length instruction encoding (1-15 bytes) with register operands encoded in the ModRM byte and SIB byte for addressing modes. The calling convention (System V ABI) mandates register-based argument passing — RDI, RSI, RDX, RCX, R8, R9 for integer arguments — enabling leaf functions to execute without accessing the stack at all. C++ virtual function calls emit two loads: mov rax, [rdi] (vptr from object) and call [rax+offset] (vtable entry). The RFLAGS register, implicitly set by arithmetic and cmp/test, encodes the result of every operation and is consumed by conditional jump instructions (je, jg, etc.) — making it a zero-overhead control-flow mechanism.
