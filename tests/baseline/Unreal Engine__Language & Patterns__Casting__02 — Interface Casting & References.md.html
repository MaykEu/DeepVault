Casting to/from UINTERFACE types uses a completely different mechanism:

Source
Engine/Source/Runtime/CoreUObject/Public/UObject/UObjectBaseUtility.h — Lines 666–675

/**

  • Returns a pointer to this object safely converted to a pointer of the 
  • specified interface class.
*/
COREUOBJECT_API void* GetInterfaceAddress( UClass* InterfaceClass );

When you write Cast(MyObject), the TIsIInterface trait detects that To is an interface. Cast then calls MyObject->GetInterfaceAddress(UMyInterface::StaticClass()) which looks up the interface offset in the UClass's internal map of implemented interfaces. This is more expensive than a bit-flag check (~20–40 cycles) but still faster than dynamic_cast's vtable walk.

How TIsIInterface Detects Interfaces
TIsIInterface is a template that answers: "Is T a UInterface?" It uses SFINAE (Substitution Failure Is Not An Error) — the compiler tries to match a specialization that checks for _getUObject() (a method all UINTERFACE types have). If the type has that method, the specialization succeeds → Value = true. If not, the specialization silently fails → the default kicks in → Value = false.
This happens entirely at compile time. if constexpr (TIsIInterface::Value) is resolved before the binary is generated. The interface path only exists in compiled code when To IS an interface. The class path only exists when To is a class. Zero runtime branching to decide which mechanism to use.

// How TIsIInterface works:
template <typename T, bool bIsAUObject = std::is_convertible_v<T*, const volatile UObject*>>
struct TIsIInterface { enum { Value = false }; };
// For non-UObject types, it checks if UClassType::StaticClassFlags has CLASS_Interface
template <typename T>
struct TIsIInterface<T, false>
{
 template <typename U> 
 static char (&Resolve(typename U::UClassType*))[(U::UClassType::StaticClassFlags & CLASS_Interface) ? 2 : 1];
 template <typename U> static char (&Resolve(...))[1];
 enum { Value = sizeof(Resolve<T>(0)) - 1 };
};

Hard References (UPROPERTY pointers)

UPROPERTY()
TObjectPtr<AActor> MyActor;
// Direct Cast (uses TObjectPtr overload — Casts.h lines 315–370)
AActorDerived* Derived = Cast<AActorDerived>(MyActor);

The TObjectPtr overload of Cast() resolves the handle, then does the same bit-flag or IsA check.

Soft References (TSoftObjectPtr / FSoftObjectPath)

UPROPERTY()
TSoftObjectPtr<AActor> SoftActor;
// ❌ DOES NOT WORK — Cast operates on live UObject pointers
AActorDerived* Derived = Cast<AActorDerived>(SoftActor); // Compile error
// ✅ Must load first:
if (SoftActor.IsValid() || SoftActor.LoadSynchronous())
{
 AActorDerived* Derived = Cast<AActorDerived>(SoftActor.Get());
}

Cast() works on live in-memory UObject pointers, not asset paths. You cannot cast across a soft reference without loading the object first.

TSubclassOf Casting

// Casts.h lines 428–441
template <typename To, typename From>
UE_FORCEINLINE_HINT TCopyQualifiersFromTo_T<From, To>* Cast(const TSubclassOf<From>& Src)
{
 return Cast<To>(*Src);  // dereferences TSubclassOf → UClass*
}

Casting a TSubclassOf checks whether the stored UClass is a child of the target type — conceptually: "is this class a subclass of that class?"
